# One Line 玩家说明规范

本文档定义五个正式玩法家族的玩家可见说明。它是玩法入口、模式页、首局提示和结算文案的共同语义来源；实际前台文案集中在 `src/config/gameExplanations.js`。

## 1. 使用方式

- 玩法入口只回答“这局要做什么”，控制在一句内。
- 首局提示只回答“现在先做哪一步”，不重复整套规则。
- HUD 只保留当前关卡、当前规则与进度，不堆叠教学句。
- 失败反馈指出可回看的信息；完成反馈确认规则或路径已经成立。
- 当规则变化时，先更新本文档和统一文案源，再更新任何单独页面。

## 2. 玩法的统一说明

| 玩法 | 入口说明 | 首局提示 | 完成状态 |
| --- | --- | --- | --- |
| 经典模式 | 从 1 出发，按数字顺序连线，覆盖整张棋盘。 | 从 1 出发，按顺序连接；只能上下左右移动。 | 路径已完成 |
| 八向连线 | 从 1 出发，按数字顺序连线；斜向也可以走，路线不能交叉。 | 从 1 出发，按顺序连接；上下左右和斜向都可以走，路线不能交叉。 | 路径已完成 |
| 隐迹连线 | 利用少量关键数字，推演一条覆盖全盘的路线。 | 从 1 出发，先规划两个关键数字之间恰好需要走几步。 | 推理完成 |
| 经典传送门 | 上下左右和斜向都能走，路线不能交叉；进入入口后，手动连到高亮出口再继续。 | 按顺序连线，斜向也可以走；进入入口后，下一步连到高亮出口。 | 路径已完成 |
| 单星谜阵 | 每行、每列、每片星域各放 1 个星点；星点不能相邻。 | 棋盘内教学分步说明标记 X 与放置星点。 | 规则已满足 |
| 双星谜阵 | 每行、每列、每片星域各放 2 个星点；星点不能相邻。 | Lv.1 说明基础规则；Lv.2–9 依当前盘面分步练习八邻格、配额、容量与传播；Lv.10 自主毕业。 | 规则已满足 |

## 3. 统一术语

- `路径`：One Line 四种连线玩法中，按数字顺序经过的路线。
- `关键数字`：隐迹连线中展示出来、用于分段推理的数字。
- `入口` / `出口`：经典传送门的一对跳转格；进入入口后，出口会高亮。
- `星点`：Star Line 中玩家放置的对象；不用“星星”指代规则对象。
- `星域`：Star Line 中由连续边界圈出的区域。
- `X`：Star Line 的排除标记；表示该格不能放星点。

避免使用“配额”“全局唯一解”“targetSteps”等内部或实现术语作为首次玩家说明；这些概念如有必要，应转成玩家当前能执行的动作。

## 4. 一致性检查

- 同一玩法在首页、玩法入口、首局提示和结算页不出现互相矛盾的移动或目标描述。
- Star Line 的单星 / 双星只表示行、列、星域内的星点数量，绝不表示通关评分。
- Portal 必须说明“手动连到高亮出口”，不能写成自动传送。
- 八向连线和经典传送门的说明必须包含“路线不能交叉”；路线交叉被拒绝时的提示必须指出交叉原因，不得复用“请从当前路径末端继续”。
- Hidden 的说明必须保留“关键数字”和“分段推演”，不能退化成普通隐藏数字玩法。
