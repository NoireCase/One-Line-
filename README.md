# One Line [Test by DeepSeek]

**One Line** 是一款以路径规划为核心、以解谜乐趣为目标的单机休闲 Puzzle 游戏。

玩家从数字 `1` 开始，观察棋盘上的已知信息，推理隐藏数字的位置，并按顺序完成一条覆盖全盘的一笔画路线。

[当前版本：v0.11.4](CHANGELOG.md)

[在线游玩](https://one-line-rho.vercel.app/)

## 游戏玩法

1. 从数字 `1` 开始按住并拖动。
2. 按照 `1 → 2 → 3...` 的顺序连接方块。
3. 路线不能交叉，也不能重复经过同一个格子。
4. 部分数字会被隐藏，需要根据周围数字和当前路线判断下一步。
5. 明显的错误连接会损失生命；生命归零后本局挑战失败。

游戏的核心节奏是：

```text
观察 → 思考 → 规划 → 完成一笔画
```

## 当前内容

游戏目前包含两种核心玩法：

| 玩法 | 路线特点 | 当前关卡 |
| --- | --- | ---: |
| 经典模式 | 从5×5小棋盘开始，逐步解锁斜向连接，最终征服9×9终极挑战 | 45 |
| 传送门谜题 | 穿过入口，选择正确出口，完成一条不断开的路径 | 9 |

玩家可以查看每种玩法的完成度、关卡状态、星级和最好成绩。

游戏进度、成绩、金币、道具和中途存档保存在当前浏览器中，不需要账号或网络同步。

## 关卡与完成度

关卡按连续编号展示：

- 经典模式共 45 关，棋盘从 5×5 逐步升级至 9×9。
- 在第 6 关解锁斜向连接，路线更加自由。
- 传送门谜题共 9 关，独立关卡列表。
- 通关后依次解锁下一关。
- 已完成关卡显示星级和最好成绩。
- 可挑战、已完成、未解锁三种状态会在关卡列表中明确显示。
- 游戏中保存退出后，可以从首页直接继续。

## 星级与生命

生命表示本局可以承受的明显失误次数。错误连接隐藏节点会损失生命，无效位置或无法连接的操作不会推进路线。

当前普通关卡会根据本局结算结果获得星级和分数。通关后可以查看：

- 星级
- 完成分
- 时间加成
- 生命加成
- 连击加成
- 总分和金币奖励

## Hidden 挑战

Hidden 挑战是模式毕业挑战，当前版本尚未开放。

开放后将采用以下成长路线：

```text
完成普通关卡
↓
解锁 Hidden
↓
完成隐藏挑战
↓
获得永久模式认证
```

Hidden 不作为另一组刷星关，也不加入排行榜、赛季或限时要求。

## Portal 谜题

传送门谜题使用隐藏传送门规则：

1. 未访问的传送门显示为 `?`。
2. 进入入口后，对应出口会亮起。
3. 下一步必须手动连接到亮起的出口。
4. 到达出口后，继续按照数字顺序规划路线。
5. 已访问的传送门会恢复显示路径数字。

当前共有 9 个 `5x5` 传送门关卡，并记录通关星级与最好步数。

## 本地运行

需要安装 Node.js。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

代码检查：

```bash
npm run lint
```
