# One Line

**One Line** 是一款以路径规划为核心、以解谜乐趣为目标的单机休闲 Puzzle 游戏。

玩家从数字 `1` 开始，观察棋盘上的已知信息，推理隐藏数字的位置，并按顺序完成一条覆盖全盘的一笔画路线。

[当前版本：v0.15.0](CHANGELOG.md)

[在线游玩](https://one-line-rho.vercel.app/)

## 游戏玩法

1. 从数字 `1` 开始按住并拖动。
2. 按照 `1 → 2 → 3...` 的顺序连接方块。
3. 路线不能交叉，也不能重复经过同一个格子。
4. 部分数字会被隐藏，需要根据周围数字和当前路线判断下一步。
5. 明显的错误连接会损失生命；生命归零后本局挑战失败。

游戏的核心节奏是：

```text
观察 → 思考 → 规划 → 完成一笔画
```

## 当前内容

游戏目前包含五种独立玩法入口：

| 玩法 | 路线特点 | 当前关卡 |
| --- | --- | ---: |
| 经典模式 | 从 5×5 小棋盘开始，按数字顺序一笔画填满全盘 | 60 |
| 八向连线 | 独立斜向连接玩法，路线规划更灵活 | 60 |
| 极简线索（Hidden） | 只给关键数字，分段推理完整路线。5×5 Easy → 7×7 Medium → 7×7 Hard | 60 |
| 经典传送门 | 按数字顺序穿过传送门，完成一条不断开的路径 | 8 |
| 传送门收集 | 自由顺序收集金币，利用传送门抵达终点 | 2 |

玩家可以查看每种玩法的完成度、关卡状态、星级和最好成绩。

游戏进度、成绩、金币、道具和中途存档保存在当前浏览器中，不需要账号或网络同步。

## 关卡与完成度

五种玩法各自独立关卡列表：

- 经典模式共 60 关（easy 10 / medium 20 / hard 30），棋盘从 5×5 逐步升级至 9×9。
- 八向连线共 60 关（easy 10 / medium 20 / hard 30），作为独立玩法入口存在。
- 极简线索（Hidden）共 6 关（5×5 MVP demo），关键数字分段推理，暂不做星级和道具。当前为 MVP 阶段，用于验证分段关键数字推理玩法是否成立。
- 经典传送门共 8 关，5×5 棋盘。
- 传送门收集共 2 关，7×7 棋盘（早期样板阶段）。
- 通关后依次解锁下一关。
- 已完成关卡显示星级和最好成绩。
- 可挑战、已完成、未解锁三种状态会在关卡列表中明确显示。
- 游戏中保存退出后，可以从首页直接继续。

## 星级与生命

生命表示本局可以承受的明显失误次数。错误连接隐藏节点会损失生命，无效位置或无法连接的操作不会推进路线。

当前普通关卡会根据本局结算结果获得星级和分数。通关后可以查看：

- 星级
- 完成分
- 时间加成
- 生命加成
- 连击加成
- 总分和金币奖励

## 极简线索（Hidden）

极简线索是 One-Line 的新增独立推理玩法。玩家只看到棋盘上的少量关键数字，需要根据数字差值（段长约束）和空间限制，分段推理出完整的一笔画路线。

当前为 v0.14.0 MVP 阶段，提供 6 个 5×5 demo 关卡。玩法核心是「只给关键数字，推完整路线」——与 Classic 的局部推进式推理有本质区别。

MVP 当前不包含星级、金币、道具系统、自动生成和 7×7/9×9 关卡。后续方向取决于 5×5 demo 的验证结果。

## Portal 谜题

Portal 分为两种玩法：经典传送门与传送门收集。

### 经典传送门

沿用隐藏数字与传送门规则：

1. 未访问的传送门显示为 `?`。
2. 进入入口后，对应出口会亮起。
3. 下一步必须手动连接到亮起的出口。
4. 到达出口后，继续按照数字顺序规划路线。
5. 已访问的传送门会恢复显示路径数字。

当前共有 8 个 `5×5` 经典传送门关卡，记录通关星级与最好步数。

### 传送门收集（Portal 2.0）

自由路径收集玩法，与经典传送门有本质区别：

1. 不要求按数字顺序，不要求走完整张棋盘。
2. 必须收集所有金币（`●`），通过传送门抵达终点（`E`）。
3. 传送门踩入后自动传送到出口，无需手动第二步操作。
4. 金币未全部收集前，终点不可通行。
5. 不使用 Classic 道具栏（恢复/排除/提示），HUD 以步数为核心评价。
6. 步数越少，星级评价越高。

当前为早期样板阶段，仅有 2 个 `7×7` 关卡。

## 本地运行

需要安装 Node.js。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

代码检查：

```bash
npm run lint
```

运行测试：

```bash
npm run test
```

`npm run test:ui` 可在 Playwright UI 模式下调试测试。
