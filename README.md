# One Line

**One Line** 是一款以路径规划为核心、以解谜乐趣为目标的单机休闲 Puzzle 游戏。

玩家从数字 `1` 开始，观察棋盘上的已知信息，推理隐藏数字的位置，并按顺序完成一条覆盖全盘的一笔画路线。

游戏当前以 **Linebook** 谜题书作为入口外壳，聚合 One Line 及其它玩法；One Line 仍是核心的路径解谜玩法。

[当前版本：v0.27.0](CHANGELOG.md)

[在线游玩](https://one-line-rho.vercel.app/)

## 游戏玩法

1. 使用鼠标或触摸板从数字 `1` 开始按住并拖动。
2. 按照 `1 → 2 → 3...` 的顺序连接方块。
3. 路线不能交叉，也不能重复经过同一个格子。
4. 部分数字会被隐藏，需要根据周围数字和当前路线判断下一步。
5. 明显的错误连接会损失生命；生命归零后本局挑战失败。

游戏的核心节奏是：

```text
观察 → 思考 → 规划 → 完成一笔画
```

## 当前内容

游戏当前包含两个玩法家族，共六个正式玩法：

### One Line 家族（线序谜阵）

按数字顺序一笔画连线，覆盖整张棋盘。使用鼠标或触摸板拖动操作。

| 玩法 | 核心差异 | 关卡数 |
| --- | --- | ---: |
| 循序寻踪 | 四向移动，从 5×5 逐步升级至 9×9 | 60 |
| 隐迹寻踪 | 只给少量关键数字，分段推理完整路线 | 60 |
| 八向寻踪 | 支持八向（含斜向）连接，路线规划更灵活 | 60 |
| 跃迁寻踪 | 按数字顺序穿过传送门，完成一条不断开的路径 | 30 |

### Star Line 家族（星线谜阵）

在棋盘上放置星点，满足行、列、星域的数量要求。使用鼠标单击/拖动操作。

| 玩法 | 核心差异 | 关卡数 |
| --- | --- | ---: |
| 单星谜阵 | 每行、每列、每片星域各放 1 个星点 | 60 |
| 双星谜阵 | 每行、每列、每片星域各放 2 个星点 | 60 |

两个家族的进度、成绩、金币、道具和中途存档各自独立，保存在当前浏览器中，不需要账号或网络同步。

## 关卡与完成度

- One Line 家族共 210 关：循序寻踪 60 关（easy 10 / medium 20 / hard 30）、隐迹寻踪 60 关（Easy 5×5 10 关 + Medium 7×7 20 关 + Hard 7×7 30 关）、八向寻踪 60 关（easy 10 / medium 20 / hard 30）、跃迁寻踪 30 关（5×5 与 7×7 手工关卡）。
- Star Line 家族共 120 关：单星谜阵 60 关（Lv.1–20 基础、Lv.21–60 扩展）、双星谜阵 60 关（Lv.1 legacy 静态教学、Lv.2–9 proof-driven 教学、Lv.10 自主毕业课、Lv.11–60 正式进阶）。
- **合计 330 关。**
- 通关后依次解锁下一关。
- 循序寻踪、八向寻踪、跃迁寻踪的已完成关卡显示星级和最好成绩；隐迹寻踪、单星谜阵、双星谜阵不展示通关星级评定。
- 关卡选择以章节呈现，每页固定展示 10 关（5×2 网格）。
- 首次通关全部关卡后，关卡页进入 sealed 总览状态，展示通关成就并可进入二次重玩模式。
- 二次重玩使用独立存档（`cg_level_select_replay_v1`），不影响首次通关记录。
- 关卡页支持水平翻页（分页按钮、触摸板横向 wheel、鼠标拖动），每页最多 10 关，最后一页不足 10 关时只渲染真实关卡。
- 游戏中保存退出后，可以从首页直接继续。

## 星级与生命

生命表示本局可以承受的明显失误次数。错误连接隐藏节点会损失生命，无效位置或无法连接的操作不会推进路线。

经典模式、八向连线、经典传送门 / 空间传送会根据本局结算结果获得星级或最好成绩。通关后可以查看：

- 星级
- 完成分
- 时间加成
- 生命加成
- 连击加成
- 总分和金币奖励

## 隐迹寻踪（Hidden）

隐迹寻踪是 One Line 家族的独立推理玩法。玩家只看到棋盘上的少量关键数字，需要根据数字差值（段长约束）和空间限制，分段推理出完整的一笔画路线。

自 v0.15.0 起已完成 60 关（Easy 5×5 10 关 + Medium 7×7 20 关 + Hard 7×7 30 关）。玩法核心是「只给关键数字，推完整路线」——与循序寻踪的局部推进式推理有本质区别。Hard 最终段 #56–#60 为 6-key 强化版，#60 作为终局大考。9×9 Hidden Master / EX 仅作为未来探索方向。

隐迹寻踪不接入星级、金币、道具系统或自动生成流水线。HUD 显示剩余尝试次数，最后一次错误会保留棋盘反馈后再进入失败面板。后续方向以 60 关质量打磨和个别关卡替换为主。

## 跃迁寻踪（Portal）

跃迁寻踪是 One Line 家族的传送门路径玩法，当前仅保留经典传送门 / 空间传送。Portal Collect / 传送门收集（Portal 2.0）已在 v0.15.0 移除。

沿用隐藏数字与传送门规则：

1. 未访问的传送门显示为 `?`。
2. 进入入口后，对应出口会亮起。
3. 下一步必须手动连接到亮起的出口。
4. 到达出口后，继续按照数字顺序规划路线。
5. 已访问的传送门会恢复显示路径数字。

当前共有 30 个手工关卡，包含 5×5 与 7×7 棋盘，记录通关星级与最好步数。

### 星线谜阵（Star Line）

Star Line 是独立的星域逻辑玩法家族：

1. 在每一行、每一列、每片星域放入指定数量的星点；星点不能相邻。
2. 单星表示每行、每列、每片星域各 1 个星点。
3. 双星表示每行、每列、每片星域各 2 个星点。
4. 提供放置星点、排除 X、清除三种工具；排除和清除支持连续拖动。
5. 支持最近 20 次鼠标棋盘操作撤销，一次拖动整体记为一步。
6. 通关按规则判定，不直接比对 solution。

当前可玩 Star Line 共 120 关：单星 60 关、双星 60 关。所有可玩关卡均通过 solver 唯一解验证和 validator 全项检查。

正式玩家路径：

- 关卡选择页显示阶段说明、棋盘尺寸（N×N）和单星 / 双星标签。
- 游戏 HUD 显示棋盘尺寸、单星 / 双星、星点进度。
- 首次进入单星谜阵显示操作教学和规则教学；首次进入双星阶段显示 proof-driven 教学课程（Lv.1–10）。
- 单星和双星使用不同的结算等待时间。
- 关卡列表只展示完成 / 可挑战 / 未解锁状态，不展示通关星级评定。

Playtest Panel / GM 面板是开发测试工具，不是正式玩家功能。它仅在开发环境或 URL 带 `?playtest=1` 时显示，用于跳关、查看关卡 metadata、显示 solution overlay、重置当前关和清空 Star Line 存档等人工测试。

视觉上，星域棋盘区域配色已调整为低噪音的深色逻辑棋盘风格，并修复 10×10 区域缺色问题。

## 本地运行

需要安装 Node.js。

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

代码检查：

```bash
npm run lint
```

运行测试：

```bash
npm run test
```

关卡质量门禁与 production smoke：

```bash
npm run test:quality
npm run build
npm run test:production-smoke
```

GitHub Actions 会在 pull request 与推送到 `main` 时执行关卡质量验证、production smoke、构建与 Chromium E2E。`?playtest=1` 仍是授权的私人试玩入口，不属于 production smoke 的失败条件。

`npm run test:ui` 可在 Playwright UI 模式下调试测试。
